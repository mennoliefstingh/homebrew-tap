# homebrew-tap

Homebrew tap for [mennoliefstingh](https://github.com/mennoliefstingh)'s tools.

## Install

```sh
brew tap mennoliefstingh/tap
brew install daily-motd
```

## Tools

| Formula | Description |
|---------|-------------|
| [daily-motd](https://github.com/mennoliefstingh/daily-motd) | Generic daily terminal message-of-the-day CLI |
